# Карта покрытия Бишкека — ТЗ 7, Осенний хакатон INAI 2026

По замерам сигнала строим карту покрытия сеткой 200×200 м, находим слабые зоны и выбираем
две площадки для новых базовых станций, которые закрывают больше всего слабых квадратов.

**Выполнено 5 из 5 обязательных пунктов и 3 из 3 бонусов** — таблица ниже.
Как всё устроено, простым языком: [docs/how-it-works.md](docs/how-it-works.md).

## Для жюри: запуск одной командой

Нужен только Python 3.10+. Скрипт сам создаст окружение `.venv` и поставит зависимости.

```bash
./run.sh <папка_с_данными>      # Linux / macOS
run.bat <папка_с_данными>       # Windows
```

В папке должны лежать `measurements.csv`, `towers.csv`, `candidates.csv`. Без аргумента берётся `data/`.

Ответ — в **`out/result.json`**. Сверить с эталоном по правилам автопроверки из ТЗ
(пара площадок, отброшенные строки ±5%, 2 из 3 худших квадратов):

```bash
python check.py out/result.json <эталон.json>
```

Посмотреть, как считалось, по шагам ТЗ: `./run.sh <папка> --tour` (или откройте `out/tour.html`).

## Карта

- **Чек-лист ТЗ** первым блоком панели: каждый пункт с живой цифрой; клик показывает пункт на карте.
- **Тур «Показать, как мы считали»** — 9 шагов, по одному на пункт ТЗ, с анимацией самого расчёта:
  мусор исчезает, точки собираются в квадраты, квадраты окрашиваются, раскрываются круги 1 км.
  Управление: `→` / `Пробел` / `PageDown` — дальше, `←` — назад, `Esc` — выход. Подходит для
  кликера презентаций.
- **Шкала RSRP** — гистограмма медиан с порогами; она же легенда и фильтр классов.
- **Своя пара площадок** кликом на карте или в списке, с подсказкой, сколько не хватает до оптимума.
- **Переключатели:** «Всё время / День / Ночь / Разница», «После 2 БС», «Замеры», «Тепловая карта», «Зоны 500 м».

## Параметры

| Флаг | По умолчанию | Зачем |
|---|---|---|
| `--bounds lat_min,lat_max,lon_min,lon_max` | `42.78,42.95,74.45,74.75` (Бишкек) | Границы района и начало сетки |
| `--dedup-on lat,lon,timestamp` | все поля замера | Что считать дублем |
| `--day-hours 8,20` | `8,20` | Дневные часы |
| `--out папка` | `out` | Куда писать результат |
| `--open` / `--tour` | — | Открыть карту / тур в браузере |
| `--no-map` | — | Только JSON и CSV |

## Допущения (уточнить у организаторов)

| Вопрос | Что сделано сейчас | Как поменять |
|---|---|---|
| Границы района | bbox Бишкека | `--bounds` |
| Дубль — это… | полное совпадение `lat, lon, rsrp, timestamp` после разбора чисел | `--dedup-on` |
| Битый `timestamp` | строка **не** отбрасывается (в ТЗ нет такого правила), но в день/ночь не идёт | — |
| Формат `worst_cells` | id квадрата `r32_c38`; центр и медиана в `details.json` | `covmap/grid.py: cell_id` |
| Расстояние до квадрата | до центра квадрата, `≤ 1000 м` | `Config.coverage_radius_m` |
| «Ближе 500 м» | `< 500` м исключается, ровно 500 — допустимо | `Config.min_tower_distance_m` |
| Числа вида `42,87`, `−95` | не число → отбрасывается | `covmap/clean.py: to_number` |

## Для разработчика команды

**1. Получить проект**

```bash
git clone https://github.com/KUMA-ORIGINAL/inai-coverage-map.git
cd inai-coverage-map
```

**2. Запустить** — та же одна команда, она же поставит зависимости в `.venv`:

```bash
run.bat data/sample --open      # Windows
./run.sh data/sample --open     # Linux / macOS
```

Откроется карта на тестовых данных. Настоящие данные кладите в `data/` и запускайте без аргумента.

**3. Тесты** (44 штуки, ~2 секунды):

```bash
.venv\Scripts\python -m pytest       # Windows
.venv/bin/python -m pytest           # Linux / macOS
```

**4. Где что менять**

| Хочу поменять | Файл |
|---|---|
| Пороги, радиусы, границы района | `covmap/config.py` |
| Правила очистки | `covmap/clean.py` |
| Сетку, цвета, худшие квадраты | `covmap/grid.py` |
| Выбор площадок | `covmap/placement.py` |
| Вид карты, тур, тексты | `covmap/templates/coverage_map.html` (после правки перезапустить `run.bat`) |
| Какие данные уходят в карту | `covmap/viz.py` |

**5. Отправить изменения**

```bash
git pull                     # забрать чужие изменения
.venv\Scripts\python -m pytest   # всё зелёное? (Linux/macOS: .venv/bin/python -m pytest)
git add -A
git commit -m "что сделал"
git push
```

Перед сдачей: проверить, что `git clone` в чистую папку + `run.bat` работает, и заполнить раздел ниже.
Последний push — до 08:45.

## Тесты

44 теста: гаверсинус, размер квадрата, пороги цветов, каждое правило очистки (включая границы
диапазона, BOM, `;`, короткие строки), правило 500 м, радиус 1 км, отсутствие двойного учёта,
контрпример для жадного алгоритма, сквозной прогон, самопроверка по правилам жюри, пять случайных
наборов с мусором (число отброшенных строк совпадает точно), `dropped_rows.csv` построчно,
отсутствие внешних скриптов в карте.

Тестовый датасет с заранее известным мусором (ожидаемые числа — в `expected.json`):

```bash
python -m covmap.sample_data --out data/sample
```
